# 🏺 أرجوس 1600 — لعبة حياة عالم مفتوح سنة 1600م

لعبة ويب عربية (RTL) تعيدك إلى سنة 1600م: تُولد كشخص عادي عمره 16 سنة، تصمّم شخصيتك
(الاسم، مدينة الميلاد، الدولة، الجنس)، فيولّد الذكاء الاصطناعي عائلتك وخلفيتك القصصية،
ثم تشق طريقك في عالم مفتوح: تعليم، مهن، سفر، ثروة، سمعة، وترقٍّ في المناصب حتى الوزارة.

## التقنية
- Node.js + Express + `node:sqlite` (مدمجة في Node 22+، بدون native dependencies)
- جلسات تسجيل دخول بسيطة (sha256 + ملح لكل مستخدم)
- واجهة عربية mobile-first مع شريط تنقّل سفلي (حياتي / المهنة / العائلة / الأحداث / حسابي)

## التشغيل محليًا
```bash
npm install
npm start          # http://localhost:3000
```

## النشر على Render
- Build Command: `npm install`
- Start Command: `npm start`
- متغيرات البيئة: `PORT` (تلقائي من Render)، `DB_PATH` (مثال: `/var/data/game.db` مع قرص دائم)
- `SKIP_LLM=1` لتخطّي توليد الخلفية بالذكاء الاصطناعي (يُستخدم النص القاعدي)
- `ALLOW_TEST_HOOKS=1` مخصصة للاختبارات فقط — **لا تفعّلها في الإنتاج**

## نظام اللعب
- 10 دول حقيقية سنة 1600 (العثمانية، الصفوية، المغول، مينغ، إسبانيا، إنجلترا، فرنسا، المغرب السعدي، روسيا القيصرية، البندقية)
- لكل دولة 5-6 مدن حقيقية وسلّم مناصب من 6 درجات بشروط (ثروة/سمعة/تعليم)
- توليد العائلة: قاعدي أولًا (طبقات مرجّحة + أسماء + أعمار منطقية) ثم طبقة LLM مجانية
  عبر pollinations (مهلة 20 ثانية، لا تكسر اللعبة عند الفشل أبدًا)
- الساعة: زر «تقدّم شهر» يدوي (بحد دقيقة بين الضغطات) + تقدّم تلقائي كل ساعة حقيقية = شهر لعب
- أحداث شهرية عشوائية بتأثيرات رقمية حقيقية (مرض، وباء، حرب، تجارة، قحط، رخاء…)
- الشيخوخة بعد 50 سنة تخفض الصحة، والموت عند health=0 مع شاشة نهاية وإمكانية شخصية جديدة
